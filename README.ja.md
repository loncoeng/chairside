# chairside

*[English version](README.md)*

マカオの美容室1軒のための、予約と顧客の管理です。セット面9台、シャンプー台
3台、そして店が実際に受け取る3つの通貨に合わせて作っています。

マクロが少し足された Excel を置き換えるものです。

---

## 汎用の予約システムにしなかった理由

GitHub で `appointment-booking` を検索すると652件、`reservation-system` で
762件が出てきます。上位に並ぶのは何年もかけて育ったものばかりです。**いま
から汎用のものを作っても、既に良くできているものの薄い版にしかなりません。**

**1軒に絞ると、汎用のものには書けないことが書けます。** 入れなかった機能を、
理由つきで並べられるという点です。その一覧は [DESIGN.ja.md](DESIGN.ja.md)
にあり、このリポジトリで面白いのはむしろそちらです。

## スキーマを決めたもの

**まず部屋を数えました。** セット面9台、シャンプー台3台、スタイリスト8人。
上限になるものが種類ごとに違うので、ひとまとめの「席」にはしていません。

| | 台数 | |
|---|---|---|
| セット面 | 9 | スタイリストより1台多いだけ。カラーの放置中は1人が2台使う |
| シャンプー台 | 3 | 1日の稼働は47%。ただし来店が夕方に集中する |

**止める指摘と、知らせる指摘を分けています。** 同じスタイリストが同時に2か所
にいるのは明らかな誤りなので受け付けません。セット面が10台目になる、シャンプー
が4件重なる、といった場合は知らせるだけにします。予約は相手を待たせたまま
入力するので、**突っぱねるシステムでは使えません。** 受付にいる人の方が、
その日の店の様子を知っています。

**辞めたスタッフは消しません。** 消すと過去の予約から担当者がいなくなり、
担当者別の売上が合わなくなります。退職を登録したときには未来の予約を並べて
引き継ぎ先を選んでもらう作りにしていて、**この地味な部分が日々の運用では
一番効きます。**

**為替レートは店が決めます。** マカオの店はほとんどが 1:1:1 で、ときどき
1:1.03 を見かけます。相場ではなく方針なので外部を呼ぶ必要がなく、会計の
たびにその時点のレートを控えます。あとで店がレートを変えても、過去の売上は
動きません。

## 同じスキーマを3か所で動かします

D1 の中身は SQLite なので、スキーマもクエリもそのまま3つの環境で動きます。

| | 用途 | ドライバ |
|---|---|---|
| Cloudflare Workers + D1 | 店の本番 | `drizzle-orm/d1` |
| Node + SQLite ファイル | 店が1台のPCで完結させたい場合 | `drizzle-orm/better-sqlite3` |
| ブラウザ内の SQLite (WASM) | 公開デモ | `drizzle-orm/sql-js` |

この形にしたので、**デモは何も共有しません。** データは訪問者それぞれの
ブラウザの中にあり、費用がかからず、荒らしようがなく、リロードで元に戻ります。

## 段階を切って作ります

**各段階の終わりに必ずデプロイします。** 一気に作って最後に一度だけ公開する
と、途中で詰まったときに何も残りません。

- [x] **1 — 骨組み。** デプロイして公開まで。データベースはまだ無し
- [x] **2 — D1 とスキーマ。** 画面がデータベースから読むところまで
- [ ] 3 — カレンダーと、予約を取る
- [ ] 4 — 顧客とカルテ
- [ ] 5 — 会計と売上
- [ ] 6 — 祝日・営業時間・スタッフ
- [ ] 7 — 公開デモ

## 動かす

```sh
npm install
npm run dev
```

`npm run dev` は画面だけを出します。API は Worker 側にあるので、両方まとめて
動かすには `npx wrangler dev` を使います。データベースはローカルの写しを見ます。

## 個人情報

顧客の氏名・連絡先・施術履歴を扱います。マカオの個人資料保護法（Lei n.º
8/2005）は EU の枠組みを踏襲しており、個人資料保護辦公室への届出は店側の
義務です。このソフトウェアが代行するものではありません。

**実データはリポジトリに入れません。** 入るのはコードとスキーマ、そして完全
に架空のサンプルだけです。CI で `publish-guard verify` を履歴ごと回し、氏名や
住所が紛れ込んでいないかを確かめます。**禁止語はコミットされた設定ファイル
ではなく Secret から渡します。** 隠したい語を禁止するために書き出すと、その
ファイル自体が公開してしまうためです。
